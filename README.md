# Portfólio — Phelipe Sousa

Site estático pronto para hospedagem em GitHub Pages, Cloudflare Pages, Netlify ou serviço equivalente.

## Adicionar os vídeos

1. Crie a pasta `assets/videos` se ela ainda não existir.
2. Adicione os arquivos com estes nomes:
   - `projeto-01.mp4`
   - `projeto-02.mp4`
   - `projeto-03.mp4`
   - `projeto-04.mp4`
3. As páginas detectam os arquivos automaticamente e substituem o aviso pelo player.

Formato recomendado: MP4 com vídeo H.264 e áudio AAC. Para carregamento rápido, tente manter cada vídeo abaixo de 50 MB.

## Publicação

Publique o conteúdo desta pasta mantendo `index.html` na raiz. Nenhum build ou servidor especial é necessário.
